Fibonacci Heap DP Demo

Traditional description

Think of this as a smart trip planner: each circle is a stop, each line has a travel cost, and the demo keeps updating the cheapest known route as new shortcuts appear.

The Fibonacci heap helps this stay fast when many route costs improve repeatedly, so you can watch the plan evolve smoothly step by step.

Show technical explanation

A Fibonacci heap is a collection of min-heap-ordered trees designed so that insert and decrease-key are amortized O(1), while extract-min is amortized O(log n).

This demo applies it to a shortest-path dynamic programming process: each node is a subproblem, each edge is a transition cost, and relaxation updates are decrease-key events.

The unique advantage appears when many states get improved repeatedly. Instead of rebuilding a priority queue, Fibonacci heaps cut and move nodes lazily with cascading cuts.

How to use

  • Set graph size and transition span with the sliders, then click Regenerate Subset.
  • Use Prev, Next, or the timeline slider to step through DP updates.
  • Watch the graph: amber edge = currently relaxed transition, blue node = focus state.
  • Watch the heap: root list and child levels shift as extract-min and decrease-key trigger linking, cuts, and cascading cuts.
