Floyd Cycle Detection Demo

Traditional description

Think of each node as a room with exactly one door to another room. If you keep walking, eventually you either loop forever or repeat the same rooms.

Floyd's tortoise-and-hare algorithm sends two walkers at different speeds. Their collision proves a loop exists, then a second pass finds the loop entry and measures its size.

Show technical explanation

The algorithm uses constant memory by storing only pointer states. At each logical time t, the state is the tuple (slow(t), fast(t)).

Once the pointers meet, resetting one pointer to the start and moving both by one finds the cycle entry after μ steps. Traversing the cycle once yields λ.

This demo frames those updates as a DP-like transition process over reusable pointer states.

How to use

  • Set node count, then change the seed to regenerate a readable tail-then-cycle graph.
  • Choose a start node and use Prev/Next or the slider to replay updates.
  • In the graph, blue highlights cycle nodes, green marks slow, amber marks fast/finder/walker.
  • Read the timeline details to connect each visual state to a Floyd phase.
