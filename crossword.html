Word Search Game

About the game

This CKPLACE word-search demo now includes two modes. Easy mode places words left-to-right or top-to-bottom with at least one-cell padding between words. Hard mode allows touching words in any direction.

How to play

  • Choose a board size and number of hidden words, then start a new game.
  • Easy mode: words are only left-to-right or top-to-bottom and do not touch.
  • Hard mode: words can touch and can appear in any direction.
  • Click or drag from a start cell to an end cell to select an entire line.
  • If your line matches a hidden word, it is marked as solved.
  • Use Solve for automated completion at any time.

Controls

Find the hidden words by selecting start and end letters.
