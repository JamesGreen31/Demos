Ckplace Tools · ARC Item Compression

Compress inventory from CSV input using the active crafting/recycling dataset.

Dataset configuration

Using ARDB default dataset.

Required per item: name, stackSize, cost, and recipe (array of ingredients with name + qty). Example root: {"items":[{"name":"Bandage","stackSize":5,"cost":250,"recipe":[{"name":"Fabric","qty":5}]}]}

How to use

  • Paste your inventory in Item,Quantity CSV format and click Analyze Compression.
  • Stack counts are always rounded up per item because every partial stack consumes a full inventory slot.
  • The optimizer prefers stack-reducing actions first. If none are available, it can use setup craft steps that temporarily hold or increase stacks to unlock better later compression.
  • In value-prioritized runs, actions are chosen by lowest value loss first, then lowest cost, and then best stack reduction.
  • Use the value-loss thresholds to compare safer vs. aggressive plans and pick the run that fits your stack goal and budget.
  • “Value” means item-price value from the dataset. Cost is value lost in a conversion: input value - output value (never below 0). Value can decrease on crafting too when ingredients are worth more than the crafted output, not only from recycling.Value loss % is cost / input value × 100.
